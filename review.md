### 2. **Алгоритмы расчета**
```python
def calculate_payroll(employee_id, period_start, period_end):
    """
    1. Получить все work_sessions за период
    2. Для каждой сессии:
       a. Определить тип дня (standard/weekend/holiday)
       b. Получить нормочас должности
       c. Если hours > норма:
          - standard_hours = норма
          - overtime_hours = hours - норма
       d. Применить множители по типу дня
    3. Суммировать по 4 категориям
    4. Рассчитать: total = Σ(hours * rate * multiplier)
    5. Применить вычеты
    """
```
